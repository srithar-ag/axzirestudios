# AxZire Studios — Official Website

> **BUILD. EXTEND. EXPERIENCE.**  
> Independent Browser Extension Development Studio by **Srithar AG**

Official website and product showcase for **AxZire Studios**, highlighting thoughtfully engineered browser extensions for **Google Chrome**, **Brave Browser**, and **Mozilla Firefox**.

---

## 🚀 Browser Extension Catalogue

### 1. **YouTube Timestamps**
- **Tagline:** Organize and revisit important YouTube video moments.
- **Description:** Never lose an important moment in a video. Organize and revisit the timestamps that matter with a dedicated browsing experience designed around YouTube.
- **Store Status:** Available on Google Chrome Web Store.
- **Platforms:** Google Chrome, Brave, Mozilla Firefox (Web Store compatible).

### 2. **Gmail Themes - Custom Themes for GMail**
- **Tagline:** Transform your Gmail with custom themes, cinematic Red Dead-inspired looks, and aesthetic styles.
- **Description:** Transform your Gmail experience with cinematic Red Dead-inspired looks, custom themes, dark mode, and aesthetic palettes. Built with zero email data access for complete privacy.
- **Store Status:** Available on Google Chrome Web Store.
- **Platforms:** Google Chrome, Brave, Mozilla Firefox (Web Store compatible).

---

## 🛠 Tech Stack

- **Frontend:** React 19, TypeScript, Vite, Tailwind CSS v4, Lucide React, Framer Motion, React Router DOM
- **Backend:** Node.js, Express.js (REST API architecture)
- **Contributions / Sponsorship:**
  - Razorpay (`https://razorpay.me/@axzirestudios`)
  - GitHub Sponsors (`https://github.com/sponsors/srithar-ag`)
- **Privacy:** 100% Client-side local storage architecture, Manifest V3 compliance, zero remote surveillance.

---

## 🏃 Running Locally

```bash
# Install dependencies
npm install

# Start full-stack development server (Port 3000)
npm run dev

# Build for production
npm run build

# Start production server
npm start
```
