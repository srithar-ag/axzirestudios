# AxZire Studios — Asset Directory Guide

This folder is configured for all official media assets for AxZire Studios.

## Assets Reference

### 1. Developer Portrait
- **Path:** `/assets/developer.jpg`
- **Usage:** Displayed on the Homepage "Meet the Developer" section and the dedicated `/developer` page.
- **Recommendation:** High-resolution square or portrait ratio (4:5 or 1:1), showing founder **Srithar AG**.
- **Note:** Until uploaded, the site displays a custom geometric studio monogram ("SAG") with full instructions.

### 2. Studio Logo
- **Path:** `/assets/logo.png` or SVG
- **Usage:** Used as fallback mark and Razorpay Checkout modal avatar.

### 3. Promotional Video
- **Path:** `/assets/extensions/youtube-timestamps/promo.mp4`
- **Usage:** Loaded by the interactive video player in the Featured Extension section.
- **Note:** An interactive HD walkthrough simulation with timestamps is built-in as an automated fallback if no MP4 is uploaded yet.

### 4. Extension Screenshots
- **Path:** `/assets/extensions/youtube-timestamps/screenshot-1.png`
- **Config file:** `src/config/studioConfig.ts`
